## Versioning

Use semantic versioning. Before 1.0, document every breaking change.

## Checklist

1. CI and CodeQL pass.
2. Windows HMI builds.
3. Relevant manual LinuxCNC tests are complete.
4. Traceability and acceptance criteria are updated.
5. Changelog is updated.
6. `CITATION.cff` and project version are updated.
7. Simulation and physical-validation labels are correct.
8. Create an annotated tag and GitHub release.
9. Include test evidence and known limitations.
