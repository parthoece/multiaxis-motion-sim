The repository includes:

- OSI-approved MIT license;
- REUSE/SPDX annotations;
- README and documentation index;
- contribution guide;
- governance;
- Code of Conduct;
- security and support policies;
- citation metadata;
- CODEparthoeceS;
- issue forms and pull-request template;
- dependency update configuration;
- CI and CodeQL;
- changelog and release process;
- architecture decision records;
- automated documentation navigation and link checks.

A public repository should enable the GitHub settings listed in `GITHUB_SETTINGS.md`.

Do not add badges for certifications or maturity programs until the corresponding questionnaire or audit has actually been completed.
